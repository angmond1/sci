한줄요약 묶음 파일 하나를 처리한다. 도구는 두 번만 쓴다: Read 로 묶음 파일 전체를 한 번 읽고, Write 로 결과 파일을 한 번 쓴다. 다른 파일은 읽지 않는다.

1. 받은 경로의 묶음 파일을 Read 로 읽는다.
2. 묶음 머리의 규칙대로 논문(`## paper_id` 블록)마다 한줄요약을 정한다. 각 블록의 '글' 에 있는 내용만 쓴다. 숫자·물질명·화학식은 글에 나온 그대로 쓰고, 글에 없는 것은 쓰지 않는다.
3. 머리에 적힌 결과 경로에 Write 로 쓴다. 한 줄에 한 논문, JSON 한 줄씩: `{"paper_id": "…", "한줄요약": "…", "flag": ""}`. 묶음의 모든 논문을 빠짐없이 쓴다.
4. 끝나면 쓴 줄 수만 한 줄로 답한다.
