# 요청 간격 정책 — 현재 규칙과 근거

현재 규칙은 SKILL.md 2절(원칙 7)과 3.3 설정이 기준이다. 이 문서는 그 근거가 된 차단 기록과 규칙이 바뀐 경위를 남긴다. 2026-04-30 의 옛 정책(90초 간격, 15편 묶음, 도구 창 방식)은 `references/_history/safe_rate_policy_260926_0121.md` 에 있고 지금은 쓰지 않는다.

## 1. 현재 규칙 (2026-09-25 확정)

- 자동 경로(API·직접 PDF): 설정 `intervals` 대로 같은 출판사 논문 사이를 기다린다. 기본값은 elsevier_api 3초, wiley 5초, springer 2초, mdpi 2초, nature 15초, generic 5초. 요청을 보내지 않은 논문 뒤에는 기다리지 않는다. 논문 한 편에 보내는 요청은 본문 1회와 PDF 1회로 제한한다.
- 웹 경로(사용자 Chrome): 같은 출판사 안에서 한 편씩 받고, 한 편이 끝나면 바로 다음 논문으로 간다. 따로 기다리지 않는다(2026-09-25 사용자 지시). 한 편에 30초~1분이 걸리므로 자연히 그 정도 간격이 된다. 탭은 하나만 쓴다(2026-09-26 확정).
- 자동 요청을 보내지 않는 출판사: ACS, RSC, Science, ECS/IOP(설정 `web_only_publishers`), 토큰 없는 Wiley, OA 가 아닌 Elsevier 구독 논문. 그 밖의 출판사도 확인 페이지나 403 이 한 번 나오면 나머지는 요청 없이 웹 경로로 넘긴다.
- 차단 문구가 보이면 그 사이트는 즉시 멈추고 30분 뒤 다시 한다. 확인 창이 눌러도 반복되면 멈추고 몇 시간 뒤 다시 한다.
- 출판사당 한 번에 수십 편 이내로 나눈다. 수백 편이 필요하면 도서관을 통해 출판사의 텍스트 마이닝 이용을 정식으로 요청한다.
- 차단 직전의 가장 짧은 간격을 찾는 시험은 하지 않는다. 우회 기법도 쓰지 않는다(SKILL.md 원칙 1).
- Elsevier API 공식 한도: 키당 초당 10회, 한 주 50,000회(https://dev.elsevier.com/api_key_settings.html, 2026-09-25 확인). 넘으면 429 응답이 오고 도구는 그 자리에서 멈춘다.

## 2. 근거가 된 기록

### 2.1 ScienceDirect 일시 차단 (2026-04-30)

- 6분 20초 동안 논문 29편의 페이지와 논문마다 여러 PDF 후보 주소를 연달아 요청하자 IP 가 일시 차단됐다. 논문 단위 거부가 아니라 IP 단위였다.
- 차단 화면 문구: "There was a problem providing the content you requested", "Please contact our support team", "Reference number:". 도구는 이 문구를 감지하면 그 사이트 묶음을 즉시 멈춘다.
- 원인은 약 13초의 짧은 간격보다 논문마다 PDF 주소 여러 개를 두드린 것이었다. 그래서 지금은 논문당 요청을 본문 1회와 PDF 1회로 제한한다.
- 이후 풀렸다(정확한 시간 기록 없음).

### 2.2 그 뒤의 실측 (2026-09-24~25)

- 도구가 띄운 Chrome(도구 창 방식)에서는 Elsevier·Wiley 확인 창이 반복되고 RSC 는 PDF 를 거부했다. 그래서 웹 경로는 사용자가 평소 쓰는 Chrome 으로 바꿨다.
- 사용자 Chrome 에서 여섯 출판사 18편씩 네 차례(총 72편)를 받는 동안 차단은 없었다. 한 탭에서 순서대로 받은 두 차례(36편, 그중 한 차례는 간격 없이)에는 확인 창이 없었다. 여러 탭 시험에서는 RSC SI 와 Science 에서 확인 화면이 몇 번 떴고 스스로 통과했다.
- 2026-09-24 연습에서 ACS 에 Cloudflare 확인 창이 한 번 떴고 사용자가 눌렀다. Elsevier 에서 확인 창이 반복된 적이 한 번 있었고 몇 시간 뒤 풀렸다.

## 3. 규칙 변천

- 2026-04-30: ScienceDirect 차단 뒤 90초 간격, 15편 묶음, 묶음 사이 30분(옛 정책).
- 2026-09-24: 도구 창 방식 폐기, 웹 경로를 사용자 Chrome 으로. 우회 기법 금지 확정. 웹 경로 30초 간격.
- 2026-09-25: 웹 경로 간격 폐지(한 편이 끝나면 바로 다음). 자동 경로는 설정 간격 유지.
- 2026-09-26: 웹 경로는 한 탭 순서대로 확정.
